# 通用显示槽位

TUI 右侧“自定义信息”提供六行，槽位编号为 **0–5**。初始均为空，显示 `--`。原 TUI 运行状态区的固定业务字段已移除，emulator 不主动为槽位读取任何 APL 信息。

## 方法

| 方法 | 作用 |
|---|---|
| `Host.display_set(slot, label, value)` | 设置或覆盖指定槽位，名称和值转换成字符串 |
| `Host.display_clear(slot)` | 清空一项，其他槽位位置不变 |
| `Host.display_clear_all()` | 清空全部槽位 |

非法槽位抛出 `ValueError`。同一编号始终对应同一行。内容在下一次 TUI 刷新时呈现，长文本按可用宽度截断并加省略号；换行与控制字符转为空格，避免破坏终端布局。

## 使用示例

在持有 Host 的宿主接线代码中写入：

```python
host.display_set(0, "当前阶段", "预处理")
host.display_set(1, "目标值", 55)
host.display_set(5, "诊断", "正常")

# 业务更新后，覆盖同一项。
host.display_set(0, "当前阶段", "运行")
host.display_clear(5)
```

例子中的字段和数值只是调用示例，没有默认绑定。读取 APL、格式化值和决定更新时机都由使用方负责；不要直接修改 `display_slots`。

槽位保存的是调用时的字符串，不是自动轮询函数或实时对象引用。当前接口与主循环在同一线程使用；从其他线程接入时应把更新调度到主循环。

供电切换与重置不自动清空槽位，保留最后一次写入内容；需要避免旧状态显示时，使用方调用清空方法或写入自己的供电状态。槽位不写入记忆存储，退出后消失。

此接口用于默认 TUI 的自定义信息区；`--plain` 旧面板显示固定负载状态。面贴本身的灯、数码管、传感器操作和事件日志不属于这些槽位。

固定负载状态与本区独立，详见 [负载状态.md](负载状态.md)。
