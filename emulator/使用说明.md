# 使用说明

## 运行环境

- Windows，使用 Windows Terminal 中的 PowerShell 或 Windows 控制台。
- Python：当前环境为 3.14；代码使用 Python 3.10 及以上的类型标注语法，其他版本尚未逐一验证。
- Visual Studio Build Tools：安装 C/C++ 编译工具，支持 `/std:c11`。
- 终端至少 126 列 × 40 行，使用能显示中文与框线的等宽字体。

当前编译环境路径固定在 `panel_sim.py` 的 `VCVARS`：

```text
C:\Program Files (x86)\Microsoft Visual Studio\18\BuildTools\VC\Auxiliary\Build\vcvars64.bat
```

本机安装位置不同时修改这个常量。仿真器调用 Win32 控制台 API，目前不支持 Linux、macOS 或输出重定向。

## 启动与退出

以下命令均在工程根目录执行：

```powershell
# 默认鼠标、键盘 TUI
python emulator/panel_sim.py

# 原版纯键盘终端面板
python emulator/panel_sim.py --plain
```

首次运行自动编译并加载 DLL；后续检测源文件、头文件、配置和导出文件的修改时间，必要时重新编译。产物位于系统临时目录下的 `apl-emulator`。

按 `Q` 退出。正常退出会恢复终端输入、输出模式和光标。

## 面板布局

按实物面贴的位置排列：

| 位置 | 键盘 | 按键名称 | 面贴长按说明 |
|---|---|---|---|
| 顶部 | 1 | Purify | Wifi (3s) |
| 左上 | 2 | Humidity | Clean (3s) |
| 右上 | 3 | Timer | Lock (3s) |
| 左下 | 4 | Light | 无 |
| 右下 | 5 | Speed | Turbo (3s) |
| 底部 | 6 | Power | 当前界面另显示 Stop dry (3s) |

六键使用单词表示。中央放置空气质量灯条、三位数码管、单位、档位与四段水位。Light 下方没有 `Sleep (3s)`；中央 `Sleep` 是档位指示。

右侧是传感器输入、固定负载、自定义槽位与最近三条事件。面板下方是保持按下、释放和重置操作。

## 按键操作

- 鼠标左键按住按键区域，松开结束本次输入。
- 键盘 `1`–`6` 对应六键，支持按下、松开和同时按键。
- 短按在松开时触发；持续 3 秒触发一次长按，松开后不再补短按。
- 点击底部对应编号的“保持按下”，切换持续按下；可同时选择多个键，再点一次释放。
- `Esc` 或“释放”清除键盘、鼠标和保持输入。释放仍是正常松键，可能触发尚未结束的短按。
- 收到终端失焦事件或窗口尺寸不足时自动释放输入。尺寸不足时库循环仍继续运行。
- `B` 或“重置”重新初始化库，清除按住状态；传感器输入、累计诊断计数和已有日志保留。

鼠标与键盘操作同一颗键时，只要任一输入仍按下，该键就保持按下。具体失焦事件是否送达取决于终端宿主。

## 当前宿主绑定的行为

| 按键 | 短按 | 长按 |
|---|---|---|
| Purify | 提示净化输出尚未规定 | 提示配网尚未规定 |
| Humidity | 提示加湿输出尚未规定 | 提示自清洁尚未规定 |
| Timer | 定时按 1–12 小时循环，再次取消 | 切换童锁 |
| Light | 切换面板灯光变量与数码管亮度 | 提示睡眠尚未规定 |
| Speed | 睡眠、一档、二档、三档、自动循环 | 极速与二档切换 |
| Power | 开关机 | 提示风干尚未规定 |

上述映射是当前宿主行为，不表示所有产品规则已经定稿。童锁由 HMI 库执行：锁定时屏蔽普通手势，允许 Timer 长按解锁。当前宿主未登记具体组合键，因此多键输入不会产生额外的组合业务。

定时到期时，宿主依据当时的整机状态切换开关机。关机回调清除童锁。风机显示的是档位状态，不代表已有实际转速输出。

## 传感器输入

点击右侧 `-` / `+` 调整：

| 输入 | 初始值 | 调节范围 | 步长 |
|---|---|---|---|
| 水位 | 2 | 0–4 段 | 1 |
| PM2.5 | 28 | 0–1000 μg/m³ | 10 |
| 湿度 | 55 | 0–100 % | 5 |
| 温度 | 25 | -20–60 °C | 1 |

这些是仿真器的输入范围，不是产品规格。键盘还保留 `[` / `]` 调水位、`-` / `=` 调 PM2.5、`,` / `.` 调湿度；旧键盘路径的 PM2.5 上限为 300，与鼠标路径不同。

水位由 APL 每拍采样。首次合法读数建立起点；从非零降到零触发缺水，从零升到非零触发恢复。目前 APL 未调用 PM2.5、湿度、温度读取接口，所以调整它们不会启动净化或恒湿控制。

## 显示限制

- 数码管当前显示定时：不少于一小时显示整小时和 H，少于一小时显示秒数，无定时为空白。
- 水位灯由宿主把输入水位映射到 HMI 属性，不表示库已经完成缺水保护业务。
- 空气质量灯亮度目前由宿主设为零，没有根据 PM2.5 自动调色。
- WiFi、滤网、UV 等未映射图标以暗色占位。右侧 UV、负离子显示已接收到的控制开关状态，未收到命令时显示未驱动。
- 事件区逐条记录手势、逻辑结果和模拟器可观察变化；按 E 展开历史，详见 [事件记录.md](事件记录.md)。

## 验证

```powershell
python emulator/panel_sim.py --self-test
python emulator/test_tui.py
```

第一条检查宿主与 APL 的已有行为；第二条检查鼠标开关机、长按童锁、多键保持、鼠标与键盘共用按键、水位输入、窗口缩小释放、定时循环及 Win32 输入结构布局。测试使用真实 DLL，但不能替代实际终端中的字体、排版和鼠标体验检查。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示终端尺寸不足 | 放大窗口或缩小字体，达到 126 列 × 40 行 |
| 找不到 vcvars64.bat | 检查 C/C++ 工具安装与 `VCVARS` 路径 |
| 编译或链接失败 | 查看报错；关闭正在加载旧 DLL 的仿真器后重试 |
| 鼠标变成文本选择 | 使用支持 Win32 控制台鼠标事件的终端；也可用键盘与底部保持按钮 |
| 净化、湿度输入没有改变输出 | 对应 APL 业务尚未实现，当前是预期行为 |
| 修改代码后界面未变化 | 退出并重新启动仿真器 |
