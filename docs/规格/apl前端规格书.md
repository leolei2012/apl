## 1. 目的与范围

本文定义库对象 `struct apl_hmi` 的职责，以及它与 `struct apl_core` 之间的数据边界。

本仓库是库，库内不创建实例。使用方持有 `struct apl`，人机是其中的 `struct apl_hmi`。人机对象不包含 `apl_core`，也不读取主控的 [`config/apl_core_config.h`](../../config/apl_core_config.h)。人机自己的编译控制和默认值在 [`config/apl_hmi_config.h`](../../config/apl_hmi_config.h)。`apl_init` 与 `apl_tick` 在 `src/apl.c`。

空气净化与加湿是否启用由主控的动态配置决定。人机按快照绘制：动态配置未启用或未编译的功能不画。

人机负责：

- 采集按键、触摸等用户操作
- 把会改变机器行为的操作交给主控
- 按主控快照绘制屏、指示灯

人机不负责：模式判断、档位计算、恒湿、滤网寿命、缺水判断、故障判定、风机与雾化输出。这些属于 [apl后端规格书](./apl后端规格书.md)。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 人机 / `apl_hmi` | 库对象 `struct apl_hmi`。本文描述这个对象 |
| 主控 / `apl_core` | 库对象 `struct apl_core`，见后端规格书 |
| `link_command` | 人机发给主控的操作 |
| `link_snapshot` | 主控发给人机的状态快照 |
| 动态配置 | 主控运行中可修改的配置。快照给出当前启用了净化、加湿中的哪几项 |

对象方法以 `apl_hmi_` 为前缀，`self` 为第一个参数。库内不放 `static struct apl_hmi`。协议结构以数据命名（`link_command`、`link_snapshot`），不把传输方向写进类型名。

## 3. 与主控的边界

判断和执行在主控。人机是操作的入口和状态的出口。

```text
用户操作 → hmi → link_command → core
core → link_snapshot → hmi → 屏 / 灯
```

规则：

1. 会改变运行行为的按键，在认出短按或长按后调用该键的回调。使用方在回调里形成 `link_command`。人机不在回调里改模式、档位、目标湿度或执行器。
2. 屏和灯只反映最新一份 `link_snapshot`。人机不用本地猜测补全主控还没确认的状态。
3. 快照标明某项功能未启用时，人机不绘制该项的图标、数值和操作入口。
4. 同一套界面逻辑覆盖全部动态配置。画不画净化、加湿，只看快照。

按键电平由宿主在 `apl_hmi_init` 注入的 `get_key_state` 一次给出六颗键。`apl_hmi_init` 让已编入的灯和三位数字管全亮，数字为 888；200 拍后熄灭，电源键半亮。使用方每 10 ms 调用 `apl_tick`，其中再调用 `apl_hmi_tick`。全亮阶段 `apl_hmi_get_powerup_lamp` 返回 1，使用方不要覆盖这些灯。短按在松开时发出，按下满 3 秒发出长按，同一次按下不重复。宿主和人机交换显示、童锁、启用标志和键回调时走 getter 和 setter。童锁、组合键和对象属性见 [HMI Datasheet](./datasheet.md)。

命令和快照的类型在 `include/apl_type.h`，字段见后端规格书第 3.2 节。本库内两边同在一个 `struct apl`，直接传结构体；跨芯片的字节协议和断连表现待定。

## 4. 配置

[`config/apl_hmi_config.h`](../../config/apl_hmi_config.h) 只做人机的编译控制和默认值。主控的 `apl_core_config.h` 不包含面板。

### 4.1 编译控制

`APL_HMI_PANEL` 选定一块按键/显示面板。对外仍是一个 `struct apl_hmi`，构建只编进该面板的实现。换面板改这个宏并换上对应实现，使用方的实例和调用不变。

| 宏 | 含义 | 未设置时 |
|---|---|---|
| `APL_HMI_PANEL` | 已登记的面板标识 | `APL_HMI_PANEL_UNSPECIFIED`（0，尚未指定） |
| `APL_HMI_COMPILE_KEY_PURIFY` | 是否编入净化键 | 1 |
| `APL_HMI_COMPILE_KEY_HUMIDITY` | 是否编入加湿键 | 1 |
| `APL_HMI_COMPILE_KEY_TIMER` | 是否编入定时键 | 1 |
| `APL_HMI_COMPILE_KEY_LIGHT` | 是否编入灯光键 | 1 |
| `APL_HMI_COMPILE_KEY_SPEED` | 是否编入风速键 | 1 |
| `APL_HMI_COMPILE_KEY_POWER` | 是否编入电源键 | 1 |

取值必须是头文件里登记过的标识，否则编译报错。具体面板待硬件确定后登记。六颗键各自选配，只能是 0 或 1，可用 `-D` 覆盖。未编入的键不认短按、长按和组合，键灯读写视为非法。键编号保持不变，采样结构仍给出六颗键的电平，库丢掉未编入的那一颗。可以六颗都不编入。这与净化、加湿的运行时启用无关。功能启用不在本文件：画不画净化、加湿，只看主控快照。

### 4.2 默认值

人机本地行为的默认值放在这个头文件。目标湿度、档位等业务默认值放在主控的 `apl_core_config.h`。当前尚无已确认的人机默认值。

## 5. 操作（link_command）

人机只在接上面板逻辑后形成操作：使用方调用 `apl_link_bind`（或 `apl_hmi_link_bind` 自己接 send）。接上后六颗键不再调用使用方的键回调。未接上时，库仍只调用键回调，使用方自己形成操作。

| 键 | 短按 | 长按 3 秒 |
|---|---|---|
| 电源 | 产测中：`FACTORY_EXIT`；否则 `POWER`（待机/风干中开机，运行中关机） | `DRY_STOP` |
| 风速 | `FAN_CYCLE` | `TURBO_TOGGLE` |
| 净化 | `PURIFY_TOGGLE` | `WIFI_PAIR` |
| 定时 | 本地定时设置（见下） | 童锁开关（本地） |
| 灯光 | 灯光开关（本地） | `SLEEP_TOGGLE` |
| 湿度 | 一体机：设置中切换预设，否则 `HUMIDIFY_TOGGLE`；加湿器：本地恒湿设置 | 一体机：进入恒湿设置；加湿器无 |
| 定时 + 风速 | — | `FILTER_RESET` |
| 电源 + 定时 | — | `FACTORY_ENTER` |

两组组合键在 `apl_hmi_link_bind` 时登记，占 4 个名额中的 2 个。机型按快照判断：净化、加湿都启用是一体机。

留在人机本地、不进 `link_command` 的行为：

1. 灯光开关。关灯后状态显示（图标、数码管、水位、氛围灯）熄灭，键灯不受影响。
2. 首次触摸唤醒：灯光关或睡眠熄屏时，第一次手势只唤醒，不执行；3 秒内再操作才执行。按住期间唤醒窗口不倒计时。进入睡眠 3 秒无操作熄屏。
3. 定时设置：第一下显示 1（定时运行中显示剩余小时数，向上取整），之后每下加 1，24 之后是 0；H 闪烁；3 秒无操作发 `TIMER_SET`。
4. 恒湿设置：一体机按 40→45→…→80→OF 循环，加湿器按 40～80 循环；数字闪烁；3 秒无操作发 `HUMIDITY_TARGET`。
5. 滤芯寿命查询：`apl_hmi_filter_query` 显示剩余寿命 3 秒。当前面板没有独立的滤芯寿命键，入口由使用方决定。
6. 童锁。

## 6. 显示（link_snapshot）

接上面板逻辑后，人机每拍按最近一份快照重画键灯、图标、数码管、水位灯、氛围灯，并播放提示音。上电全亮的 2 秒内不重画。

| 状态 | 显示 |
|---|---|
| 待机 | 电源键半亮；恢复出厂设置后数码管显示 CL |
| 风干 | 只亮电源键灯和风干图标 |
| 产测 | 全部灯光点亮，数码管 888 |
| 运行 | 见下 |

运行时：

1. 键灯：电源、风速常亮；净化键 = 净化开；湿度键 = 加湿开；定时键 = 有定时；灯光键 = 灯光开。
2. 档位图标按用户档位点亮一个；极速时档位图标全灭。
3. Wi-Fi：配网闪烁（500 ms），联网常亮。童锁、负离子、UV 图标按状态。恒湿图标 = 加湿开且目标不是 OF。
4. 滤网：到期红灯、否则白灯。强制重置后红灯闪 3 次（100 ms）再回白灯；到期后开机红灯闪 3 次（500 ms）后常亮。
5. 水位（加湿启用）：段数 = 快照段数；一段为橙色，两段以上绿色；水满时闪 4 次（100 ms）；缺水时最左一格橙色，闪烁期亮 3 s 灭 0.5 s，之后常亮。
6. 氛围灯（净化启用）：优蓝、良绿、中黄、差红。
7. 数码管：设置中显示设置值；查询中显示滤芯剩余；否则净化机型 PM2.5、加湿机型湿度，一体机每 20 秒轮换。
8. 提示音按 `beep_seq` 变化播放：重置 500 ms，强制重置 300 ms，水满 4 声，缺水 3 声，产测 500 ms，UV 报警 3 声。上电响一声。

## 7. 待确认

1. 产测组合键取电源 + 定时（三张机型表），汇总表写电源 + 风速。
2. 上电后电源键半亮（汇总表），机型表写「亮起」。
3. 当前面板没有独立的滤芯寿命键：空净也用定时 + 风速重置，查询只提供 `apl_hmi_filter_query`。
4. 定时确认后「H 常亮」与主显示单位冲突（同一时刻只亮一个单位），改由定时键灯表示有定时。
5. 一体机灯光关时的首次触摸唤醒，原表没写，按空净、加湿器的规则统一处理。
6. 恒湿图标按「恒湿生效」点亮，不按「自清洁」。自清洁没有实现。
7. 水位一段视为低于 25%，橙色。
8. 极速的呈现、产测逐个点亮的顺序原表未给。
9. 加湿器恒湿键短按也走 3 秒确认。
10. 页面结构以外的刷新率、主控无响应时的显示，待定。
