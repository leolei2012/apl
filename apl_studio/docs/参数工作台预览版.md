# 参数工作台预览版

默认首页现在采用三个步骤：**配置产品 → 仿真体验 → 导出交付**。

当前源码仿真每 1ms 调用一次 `apl_tick_1ms`，APL 内部每 10ms 执行完整业务；2秒自检、3秒长按、5秒传感器预处理及定时、风干的实际时长保持不变。单步接口支持1ms，实时仿真仍每次推进100ms；历史冻结SDK保持各自原有10ms周期。源码变化后需要重启Studio、确认产品绑定当前源码并重新启动仿真，已有会话不会自动切换。

仿真面板顶部两排氛围灯使用APL实际RGB输出：优蓝、良绿、中黄、差红；预处理、输入无效、关灯或待机时按APL状态熄灭，自检全亮时为白色。运行时桥接作为虚拟宿主绑定 `hmi_ops.set_ambient_rgb`，将已合并亮度的三通道值传到网页，页面不再固定青色或重复判断等级。当前按APL直接切换颜色，没有额外渐变；通道变化会进入事件记录。实体宿主接口见[宿主接入要求](../../apl_lib/宿主接入要求.md)。

## 使用

在 `apl_studio` 执行 `npm start`，打开 http://127.0.0.1:9190。

1. 新建产品，填写名称、勾选“净化功能”和/或“加湿功能”，选择可用 APL 版本。至少勾选一项，创建后直接进入配置；无需单独选择“一体机”类型。
2. 配置功能模块、传感器和运行参数。按键编号、宏、SDK 版本等不出现在主流程。纯净化隐藏加湿专用参数；未选配 Wi-Fi 隐藏配网时间。
3. 点击“保存并进入仿真”，再启动仿真。使用圆形面板开机、短按/长按，改变环境，观察真实负载。日志默认收在调试详情中。
4. 点击“体验完成，导出参数”，下载当前已保存修订的 Excel。仿真用于辅助体验，导出不强制要求完成某套场景验收；导出本身仍需通过参数和版本校验。

运行参数按“风机运行”“各档转速”“加湿与风干”“显示与定时”“滤网维护”“Wi-Fi 联网”分组，各组可独立展开或收起，默认展开风机运行。组标题显示可配置项数；不适用的参数和空组自动隐藏，折叠或隐藏不清空已配置值。此布局调整不改变参数表格式，也不需要重新绑定 APL 源码。

同时勾选净化和加湿后，“运行参数”显示“传感器显示切换间隔”，单位秒，默认20，范围1～3600。它控制PM2.5和湿度各自停留的时长，完整循环为两倍；从开机计时，5秒预处理也计入。仅启用一项时隐藏此配置并固定显示对应数据。

“运行参数”还提供“定时按键步进”，单位小时，默认1，范围1～24，各种功能组合都可设置。无定时时第一次短按从步进值起，后续累加，超过24回到0取消；例如2小时为2→4→…→24→0，5小时为5→10→15→20→0。已有定时时，第一次短按只查询剩余小时数，后续才按步进增加。按住连增使用相同步进；确认等待与童锁交互不变。

“运行参数”新增睡眠、一、二、三、极速五档目标转速，单位rpm，范围0～65535。缺省依次为400/600/900/1200/1500 rpm，可按产品覆盖，0目标表示停转。已有v4产品的0或自定义转速继续保留，新建产品和旧版本缺失字段采用新缺省值。自动、恒湿、风干和输入异常使用APL算出的最终输出档位对应的rpm；自动模式不另设固定rpm。仿真面板下方及负载区显示“目标转速”，由真实C getter输出，不冒充测速数据；目标变化会进入事件记录，模拟掉电时归0。

参数格式现为v6（23项数值参数、PID及内部按键映射）。已有v1/v2/v3/v4/v5产品重启服务后会提示源码/参数变化：展开“版本与来源”，点击“确认绑定当前源码”，保留原参数（包括显示间隔、定时步进）并补入新增字段默认值，然后保存。设置新参数后重新开始仿真；导出的Excel使用同一已保存值。

离开编辑页前自动尝试保存，有错误则保留当前草稿。关闭或刷新浏览器时对未保存草稿提示；页面地址记录当前产品和步骤。离开仿真步骤释放其进程，返回后需重新启动。保存期间锁定编辑，防止响应覆盖后续修改。

## 产品 PID

启用Wi-Fi模块后，在“配置产品 → 运行参数 → Wi-Fi 联网”填写产品PID字符串，例如`aaerrxvja3m7lvhz`。最多16位英文字母/数字，保留大小写和前导零，可留空。保存后会随产品修订、仿真初始化和Excel导出保留；导出到“产品信息”B22，按文本保存。关闭Wi-Fi时隐藏该分类并保留已填写PID，再次开启后继续显示。PID是Wi-Fi产品标识，不同于Studio内部UUID和工程code，不自动替换两者。旧产品确认重新绑定后补空默认值，已有PID原样保留。设备宿主通过`apl_core_get_pid`读取，实际Modbus烧录尚未接入。

## 内存估算

在“芯片与固件裁剪”中查看内存估算，填写实例数量、宿主及其他数据和安全余量，和软件栈一起计算预算。未知项保持未填写，页面不会因此判定整机能放下；Flash支持手填目标链接占用。结果随产品修订保存，可单独导出或在源码ZIP中查看。详见[内存估算](内存估算.md)。

## 通用功能裁剪

裁剪范围已扩展到定时、滤网维护、产测、运行记忆、睡眠、风干、氛围灯及各模块/传感器，不局限于Wi-Fi。自定义开关关闭后专属实现、状态和接口不编入，运行参数中无效项隐藏但保留原值；已有裁剪配置缺少新开关时按启用解释，不静默减功能。完整边界见[模块解耦与裁剪](../../docs/规范/APL模块解耦与裁剪.md)。

## 芯片与固件裁剪

“配置产品”增加芯片与固件裁剪分组，支持资源预算、五套预设及自定义编译开关，随产品修订保存。“导出交付”可导出含配置头、产品默认参数和来源清单的C源码包。仿真应用相同裁剪；纯主控模式明确禁用面板仿真。旧产品默认保持全功能，参数不能启用已裁掉的能力。完整流程和容量边界见[固件裁剪与芯片预算](固件裁剪与芯片预算.md)。

## 功能组合与自适应面贴

产品以 `purify_enabled` 和 `humidify_enabled` 两个参数表示能力，不再要求选择三个互斥机型。产品卡片和配置摘要显示实际勾选的“净化”“加湿”或“净化 + 加湿”；已有产品直接按其原参数显示，不改写已保存数据。

| 净化功能 | 加湿功能 | 仿真面贴 |
|---|---|---|
| 勾选 | 未勾选 | 左上为滤芯复位键，短按查询、长按3秒复位；显示PM2.5、H及净化状态区域，隐藏加湿键、湿度单位和水位/恒湿/风干区域 |
| 未勾选 | 勾选 | 左上为加湿键，显示湿度、H、水位/恒湿/风干区域；顶部标为联网，隐藏PM2.5、空气质量灯带、负离子与UV标识 |
| 勾选 | 勾选 | 左上为加湿键，同时保留净化和加湿区域，显示PM2.5、湿度、H；无需额外选择一体机 |
| 未勾选 | 未勾选 | 显示校验提示，禁止创建、保存、仿真和导出 |

改变功能后，保留仍适用的传感器选配和运行参数；关闭净化时清除空气质量传感器位，关闭加湿时清除湿度传感器位。新启用净化默认勾选PM2.5，新启用加湿默认勾选湿度传感器。其余模块选配与原有APL运行规则保持一致。

面贴元素按功能显示或隐藏，实际亮灭仍取真实C快照。纯净化左上键使用已有 `Filter` 输入和 `key_6` 背光，不把加湿键伪装成复位键。选配和参数修改须保存并重新开始仿真，才应用到运行中的设备。此改动无需改变参数表格式或APL源码。

运行时方案中，手动关灯会熄灭全部按键背光、数显、状态图标和水位/氛围灯，设备继续运行。首次有效按键仅临时唤醒，3秒无操作后重新全灭；唤醒后再短按灯光键恢复显示。桥接输出各段 `water_1`～`water_4` 的实际亮度，`display.water_level`表示亮灯段数，环境输入中的水位仍保持实际值；网页不拿实际水位代替灯位。历史冻结SDK继续采用其自身的灯光业务规则。

原有产品和 SDK 流程保留在 `/engineering`，首页左下角有“旧版工程工具”入口。新首页只列出运行时参数产品，原工作区产品并未删除或迁移。两类产品共用既有 SQLite 产品、修订和冲突检查。

## 实际接入

- 当前仅接入本地 **APL 0.3.0 开发版**，参数来自 `apl_lib/parameters/profile.schema.json`，Excel 布局来自同目录模板。
- 服务启动时固定一份库源码、配置、参数定义和 Excel 的内存快照；每个产品保存源码指纹。文件改动后需重启服务才能读到新版本，旧产品指纹不匹配时须明确确认重新绑定，不能继续仿真或导出。
- 默认全功能时，三种功能组合使用同样的 C 库和编译配置；选择固件裁剪后，仿真及导出包使用产品指定的编译条件，运行参数仍由仿真宿主准备的 `apl_profile` 提供，调用 `apl_init_profile` 加载，不再通过产品选配改写库宏。当前仿真仍会构建本机宿主程序，这不代表每种产品需要重新编译设备固件。
- Excel 填入已保存的参数值、产品名称、修订、APL 版本和来源指纹。未提交的开发快照不填写虚假的 Git 发布提交号。
- 仓库来源详情收在折叠区。远端仓库添加、Git Tag 发现、历史版本选择尚未接入；版本下拉只显示实际支持的本地版本。
- Modbus 寄存器表、串口收发、设备 Flash 保存及目标硬件验证尚未接入。导出的 Excel 目前供配置审查，不是已可直接写入芯片的包。

## 接口

- `GET /api/profile/catalog`：当前参数定义、源码版本及快照来源。
- 产品创建/保存沿用 `/api/products`，精确绑定 `apl.runtime-profile@0.3.0`，服务端拒绝未知字段、依赖错误、越界参数及过期源码指纹。
- 仿真沿用现有会话接口和真实 C 进程桥接。
- `GET /api/products/:id/parameters.xlsx?revision=N`：导出精确修订；产品已更新则返回409。
