# 圆形设备面板初版

依据用户提供的圆形面板稿，在产品经理工作台的「体验与验收」接入可交互面板。适用于已有产品经理工作流；工程仿真台原有样式保留。

## 使用

1. `npm start` 后打开 `http://127.0.0.1:9190`，进入产品的「体验与验收」，刷新页面加载已构建的新界面。
2. 未开始体验时显示未点亮的面板，不用虚构的888作为运行状态。点击「开始体验」，等待真实C程序准备，再点击底部电源图标开机。
3. 点击图标为短按，按住3秒为长按；图标下的3s文字提供长按快捷入口。Tab与回车也可操作，「全部按键与长按操作」保留其他已声明按键及无障碍入口。
4. 移出按键、取消触摸、失焦、切换或关闭页面会取消尚未提交的按压；长按完成后松开不再补发短按。手势仍调用已有C宿主的完整短按/长按事务，未增加原始按键电平或组合键协议。
5. 用空气质量、湿度和水位输入观察面板；「等待1秒/5秒/20秒」快速推进C设备时间，便于观察睡眠熄屏、定时和显示轮换。按键及各上下文中的动作由绑定模板执行。
6. 「运行场景验收」继续由服务器另建真实C会话运行既有标准场景。手动体验和场景结果分别呈现，不以面板动画代替验收。

## 显示与边界

- 数码管内容、亮度、单位、氛围灯、键背光和13个图标读取现有C显示快照。未点亮段保留弱轮廓，便于识别位置；轮廓不代表灯已开启。
- 仅启用描述中实际存在的按键。打印的Wifi/Lock/Turbo等文字沿用参考稿，实际动作与当前选配、上下文和绑定版本一致。
- 水位条展示已有`water_level`级数。当前宿主没有提供完整的逐段水位灯亮度及灯色，初版统一使用青色，不把它作为硬件灯色验收依据。未新增空气质量颜色、故障阈值或湿度策略。
- 样式用SVG/CSS绘制，可缩放；图标、间距和字形为初版近似，不依赖外部图片服务或新依赖。
- 体验页持续查询就绪会话，保持已打开的体验有效并同步停止状态；请求顺序标记避免旧查询覆盖新按键结果。离开页面仍停止其自有C会话。

没有改写业务库、冻结模板、产品版本绑定或真实产品数据。暂停的组合键修改不属于本轮面板改动。

## 验证

`tests/air-care-panel.test.ts`以0.4.2真实C快照检查上电888自检、待机、开机、童锁拦截、睡眠熄屏保留Sleep灯和掉电；网页还需检查点击、实际按住3秒、键盘、拖出取消和页面退出。

完整检查前为既有直接调用编译器的回归设置本机`CC`，例如当前机器：

```powershell
$env:CC='C:\Qt\Tools\mingw1310_64\bin\gcc.exe'
npm run check
```

这个路径仅使用已安装的GCC工具，不运行Qt程序。
