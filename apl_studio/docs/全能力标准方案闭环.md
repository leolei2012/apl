# 净化、加湿与一体机标准方案 0.3.0

新模板 apl.air-care@0.3.0 固定APL 0.1.3源码；旧0.1.0/0.1.1/0.2.0字节与真实产品绑定保持不变。
本版本把已实现的三能力组合接入产品经理配置、真实C场景验收和SDK交付，并不宣称整份Excel全部符合。

## 使用

从标准方案目录选择“净化、加湿与一体机标准方案”，创建产品，在产品方案选择空气净化器、加湿器或一体机。
设置开机档位、滤芯寿命和可用的风干/回差项目参数，在交互规则选择长按极速，然后保存。
体验与验收提供真实C面板、环境湿度、水位、PM及UV联锁输入；运行场景验收后才能生成并下载当前修订SDK。
SDK包含标准库、产品配置/接口、占位port、中文功能/验收/硬件文档、来源哈希及验收JSON。
真实C场景覆盖按键、Auto/睡眠、Turbo、缺水/风干、维护初始值及UV联锁。MCU链接、栈和实机验收独立进行。

## 版本与隔离

0.3.0来自唯一开发源apl_lib，不在CUCKOO维护业务副本。开发源、模板、产品修订、生成文件和C桥接均绑定指纹。
新模板需服务启动时加载；本轮验证仅使用新临时目录和独立端口，不改19191实例或真实.data。
暂停组合键的7个文件不纳入本版本提交；simulation-adapters.ts只提交支持源码0.1.3的一行。

## 复现

APL根目录运行 python tests/run_platform_checks.py；apl_studio中运行 npm run check。
新增 standard-workflow.test.ts 对三种能力组合执行真实HTTP处理、C验收、门禁、SDK消费、manifest与下载校验。
CUCKOO的 integrations/apl/tools/export_standard.mts 可从独立已提交APL导出三组合交付；target_c51/build.ps1支持 -SdkDirectory 直接消费下载SDK，无硬件链接。
