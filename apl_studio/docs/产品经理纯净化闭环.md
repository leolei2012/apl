# 产品经理纯净化试点：一页手测与交付说明

本轮面向没有编程能力的产品经理，提供“产品方案→交互规则→体验与验收→交付工程师”四步流程。开发源仍为`apl_lib/src/include/config`，实际业务由C库执行。页面只选择已实现的标准能力与交互，不要求输入代码、宏、数据类型或功能key。

体验入口已接入用户初版[圆形设备面板](圆形设备面板.md)，按键、数码管和状态灯连接实际C显示快照。

## 使用隔离演示实例

历史纯净化浏览器演示地址为`http://127.0.0.1:19191`，使用当时的独立临时数据，不是工程真实`.data`。该已运行快照保持不变，不需要重启。

现在从APL工程自行启动，使用与ProbeStation一致的入口：

```powershell
cd apl_studio
npm start
```

打开`http://127.0.0.1:9190`。新工程固定9190，启动前检查占用，冲突即退出而不改数据库、不自动换端口。端口不再由`APL_STUDIO_PORT`决定。正常启动复用工程`apl_studio/.data`，不每次创建临时空库；不自动迁移任何历史隔离演示数据。具体持久路径及保留的隔离数据覆盖见[Studio README](../README.md#设置与数据)。仅使用已安装依赖和C编译器，不启动Qt或真实设备。

## 一次完整闭环

1. 点击“新建产品”，填写中文名称，点击“创建并定义方案”。标识和模板绑定由平台生成；其他产品与工程配置保留在独立入口。
2. 在“产品方案”选择开机档位、滤芯维护小时数。标准能力包含项明确展示；净化模板保留UV/负离子复合接口，暂不提供两者独立选配，工程师需确认接线与联锁。本试点不含加湿。
3. 在“交互规则”选择风速键长按3秒是否进入/退出极速。短按保持睡眠→一→二→三→自动循环。自动调速规则为PM2.5≤35睡眠风速、36～75一档、76～150二档、>150三档；自动最低风速不进入睡眠模式或熄屏。修改后点击“保存方案”。
4. 在“体验与验收”点击“开始体验”，准备结束后用电源键开机、风速键操作；PM2.5按钮改变实际C读取的环境值。体验使用已保存的方案，配置更新后需重新开始体验。
5. 点击“运行场景验收”。服务器独立运行真实C，显示10项预期与实际结果：六个分界值、回落至35、Auto最低档不熄屏、当前长按配置及长按后的短按循环。全部通过后继续交付。
6. 点击“生成并验证交付包”。服务器核对当前验收及生成代码指纹，再编译并执行SDK消费程序；成功后下载。工程师查看源码、接口、配置、示例及`docs/product-spec.md`（中文功能交互）、`docs/acceptance-report.md`（中文结果）、`docs/hardware-checklist.md`（硬件待办）、`verification/acceptance.json`和manifest。

再关闭长按极速并保存：旧验收应标为过期，当前交付按钮禁用。重新验收应出现“关闭极速后长按不改变档位”通过；再次生成包时配置宏和实际SDK消费均检查关闭分支。历史已成功包仍可下载，保持原修订和原证据。

## 验收与代码一致性

- 产品经理请求只含产品ID、已保存修订号；服务器拒绝客户端提交成功状态或检查结果。
- 验收记录绑定产品定义指纹、修订、精确模板版本/指纹、实际库版本、执行过的生成文件指纹及C宿主驱动指纹。
- 保存新修订或模板/驱动变化使验收过期。生成时再次比较待打包代码和已执行代码，不能用旧报告验证新代码。
- 通过后的报告与中文说明进入同一归档文件集，manifest记录验收标识与指纹；下载仍校验归档内容、文件集、任务及验收元数据。编译或消费失败不能下载新包。
- 验收范围是上述场景，不包括全部按键、全部故障、MCU资源或真实硬件。模型预览与真实C验收各有独立含义。

## 版本与兼容

新增本地候选模板`apl.air-care@0.2.0`，工作流标记为`purification-pm-v1`；其业务源逐字节来自当前`apl_lib`，库版本宏仍为0.1.1，模板版本与库源码版本分别记录。`source-snapshot.json`记录来源及哈希，目录自身固定原字节。

0.1.0/0.1.1冻结内容与已有产品绑定未变，也不迁移真实数据库。旧模板继续使用原编译/消费交付流程；历史成功SDK不要求补做新流程验收。新试点明确要求当前修订的真实C验收。

标准方案只提供固定能力集、开机档位、滤芯维护和长按极速选择；显示布局及其余按键沿用模板标准。三项湿度规则、任意按键动作、自由面板排版和通用流程编排尚未纳入。

暂停中的7个组合键文件不属于本轮提交，不以其测试通过声称规格验收。工程师继续在自己的应用目录完成真实驱动、风机标定、安全联锁、存储和目标硬件验证。
