# APL Studio 界面与交互设计

## 目标与参考

simulator 面向配置、验证和交付 APL 的工程人员。界面采用浅色工作区、稳定导航、分组设置和单一主要动作，
减少同时出现的调试信息。保留 Windows 标准窗口和文件对话框，设备面贴继续使用真实的黑色圆形布局。

设计参考 Apple 官方的 [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)、
[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) 和
[Layout](https://developer.apple.com/design/human-interface-guidelines/layout)。这里借鉴导航层级、内容对齐和动作优先级，
不使用 Apple 标识、SF Symbols 文件或系统控件截图。

## 工作区结构

| 页面 | 主要任务 | 右上角主要动作 |
|---|---|---|
| 概览 | 新建 / 打开产品，了解当前产品状态和工作流程 | 配置产品 |
| 产品配置 | 编辑产品功能、运行参数、面板按键 | 应用并预览 |
| 实时仿真 | 操作面板、调整环境、查看实际输出 | 准备交付 SDK |
| SDK 交付 | 查看包内容、接入步骤和最近导出位置 | 导出 SDK |

左侧是固定的四页导航和当前产品信息。右侧页眉始终提供当前页标题、预览状态、保存入口和主要动作。
顶部菜单保留文件、仿真、视图、产品、帮助入口，支持熟悉的桌面快捷键。

## 配置和运行状态

- 产品编辑器直接嵌入页面，切换页面不销毁编辑器，不丢失草稿或当前设置页。
- 新建和打开产品进入配置页，不自动编译或重新上电。产品草稿只有通过“应用并预览”才改变运行配置；绑定源码后的代码保存会自动重建最近请求应用的配置。
- 三种产品类型使用互斥分段按钮；选择类型同步调整默认功能和对应按键。
- 常用运行参数先展示，缺水、产测、配网等参数在“更多运行参数”中展开。
- 参数仍由 ProductConfig 校验。无效配置在页面内说明原因，同时禁用应用和导出主要按钮。
- 产品更改可保存为独立文件。改回已保存的值会清除未保存标记；新建 / 打开其他文件或退出时保护未保存更改。
- “内置预览”“源码或配置待应用”“正在构建 APL”“已应用源码与配置”说明来源、构建状态及内容是否一致，不等同于人工测试通过。
- 编译失败保留旧实例，用页面反馈说明结果；需要时点击“查看详情”展开编译信息。
- 导出前仍检查配置指纹。成功后在交付页显示文件位置，提供“在文件夹中显示”，不再弹出成功确认框。

## 仿真交互

圆形面板 / 按键台在仿真卡片顶部切换。两种面板都支持鼠标、Tab 聚焦、空格 / Enter 按下松开，以及持续 3 秒长按。
切换面板不会重新初始化 APL。

供电开关与面板 Power 键分开：供电模拟外部掉电；Power 交给真实 APL 执行正常开关机。
暂停 / 继续在仿真顶部直接操作。单步、重新上电和滤芯查询位于“更多”菜单，也保留菜单栏入口。

设备检查器包含：

- **环境输入**：水位、PM2.5、湿度、温度，滑块与精确数字输入同步；提供清新 / 污染 / 缺水快捷场景。
- **运行诊断**：APL 状态、调用计数和六个通用调试槽位。
- **实际负载输出**：固定显示风机、加湿器、UV、负离子实际收到的输出，独立于诊断页签。

事件记录默认收起，为设备面贴保留空间。展开后可以筛选、控制跟随滚动，或将当前筛选结果保存为 UTF-8 文本。
记录内容仍来自原有事件系统，保留手势和逻辑结果的区别，最多 500 条。

## 视觉和输入规范

| 元素 | 约定 |
|---|---|
| 工作区 | `#f5f5f7`，侧栏 `#eeeff3`，内容卡片白色 |
| 强调色 | `#007aff`，用于主要按钮、选中状态与输入焦点 |
| 文字 | 深色正文与灰色说明分层，中文优先系统微软雅黑字体 |
| 容器 | 16 px 圆角、浅色分隔边框、常用 16 / 22 / 28 px 间距 |
| 图标 | 自绘简洁描线，资源只包含项目自己的上下箭头 SVG |
| 开关 | 继承标准 QCheckBox 语义，支持空格切换、可见焦点和可访问名称；短动画只影响外观 |
| 数字输入 | 保留步进按钮、键盘输入、范围限制；内部文本区域不能被样式裁切 |
| 反馈 | 成功操作在页面内反馈；错误说明提供按需展开的详细信息 |

快捷键：Ctrl+1～4 切换工作区，Ctrl+N 新建，Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+R 重新上电。

## 实现边界与验证

`StudioTheme` 集中管理调色板、控件样式、描线图标和开关。`ProductEditor` 管理可复用的内嵌编辑界面；
`ProductDialog` 仍可复用同一编辑器。`WorkbenchWindow` 组织四页工作区，`workbench_product.cpp` 处理配置文件与应用 / 导出。
产品配置文件格式不变；实时源码的后台构建与自动重载见[APL 开发与热重载](APL开发与热重载.md)。

`workbench --self-test` 除原有检查外覆盖：四页导航、草稿跨页保留、未应用编辑不影响运行实例、非法配置禁用、
改回原值清除未保存标记、开关键盘操作、传感器精确输入同步、数字输入文本区域、事件筛选、暂停 / 继续以及两种面板的键盘操作。
自检在系统临时目录保存 `apl-studio-overview.png`、`apl-studio-configuration.png`、`apl-studio-delivery.png`、
`apl-studio-events.png` 和仿真面板截图，用于布局检查。
