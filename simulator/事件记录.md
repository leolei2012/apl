# 事件记录

事件由宿主独立保存，不再根据最后一条 `message` 推测。同一拍中的多条事件逐条保留。

## 手势与结果分开

六个按键在 APL 触发回调时先记录 `Purify / Humidity / Timer / Light / Speed / Power 短按` 或 `长按`，再执行宿主绑定逻辑并记录结果。例如：

```text
12:30:00  Light 短按
12:30:00  灯光关
12:30:00  数码管: ('   ', 0, 0)
```

这里的手势是 APL 实际交出的回调；被童锁屏蔽、没有回调的操作不会伪造短按事件。未实现的行为只报告“尚未规定”，不报告成功。面板输出元组分别表示数码管内容、单位枚举和亮度；键灯按六键顺序，水位灯按第 1–4 段顺序。

## 记录范围

- 六键短按、长按与宿主逻辑结果。
- 水位、PM2.5、湿度、温度输入变化。
- 固定负载收到的不同输出、供电切换和重置。
- 显示槽位设置、更新、清空。
- 存储写入或擦除成功且内容变化。
- 每次发布后的键灯、水位灯、数码管输出变化。

相同输入、负载输出、槽位内容、存储内容不会重复记录。手势属于一次独立事件，连续两次相同按键动作仍分别记录。读取与空闲 tick 不产生日志。

这些是模拟器可观察的事件，不主动轮询所有 APL 私有字段；其他业务可调用 `host.emit_event("事件内容")`。兼容旧代码的 `host.message = "消息"` 也会追加一条事件，不去重。

## 查看

右侧显示最新三条，按时间从上到下排列。按 `E` 展开事件视图；`[` 看更早的 30 条，`]` 返回较新的 30 条，再按 `E` 返回面板。展开期间模拟继续运行。

内存保留最近 500 条，按发生顺序排列，同秒事件也不会互相覆盖。日志跨模拟上电、掉电和重置保留，关闭进程后不保存。

测试：`python simulator/test_events.py`，覆盖六键短按、长按不补短按、事件与结果顺序、多事件保留及同值去重。
