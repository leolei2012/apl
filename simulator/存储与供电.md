# 存储与供电

## 供电模拟

| 方法 | 行为 |
|---|---|
| `Host.supply_off()` | 模拟突然掉电；停止 tick，清除按键并丢弃 APL 运行内存 |
| `Host.supply_on()` | 重新上电，执行 APL 初始化和按键绑定 |
| `Host.supplied` | 当前是否有外部供电 |

TUI 底部按钮和键盘 `P` 切换供电；旧版 `--plain` 面板也支持 `P`。
面板 Power 键是正常开关机，不改变外部供电。掉电不调用正常关机回调，不自动保存数据。

无供电时不推进 APL，不接受面板按键，也不能重置或访问存储器。仍可改变模拟传感器；上电后读到最新输入。供电反复开启或关闭是幂等操作。

上电使用库的初始化状态，因此定时、童锁等易失状态清除。当前没有业务恢复策略，风机档位等也回到库默认值。诊断计数、事件日志、外部传感器输入和非易失存储保留。

## 提供给宿主接线的存储方法

| 方法 | 参数与返回 |
|---|---|
| `Host.memory_read(offset, length)` | 从字节偏移读取指定长度，返回 `bytes` |
| `Host.memory_write(offset, data)` | 在指定字节偏移写入字节数据 |
| `Host.memory_erase()` | 全部恢复为 `0xFF` |

三者都要求供电。越界抛出 `ValueError`，无供电抛出 `RuntimeError`，文件读写失败抛出 `OSError`，由接入方处理。

默认容量 **4096 字节**，初始内容全为 `0xFF`。首次有效写入时创建文件；TUI 和旧面板使用 `simulator/data/nvram.bin`，退出程序后仍保留。目录已加入 simulator 的 `.gitignore`。

`Host(lib)` 默认使用独立的内存存储，便于测试；需要跨进程保留时显式传入文件存储：

```python
from pathlib import Path
from panel_sim import Host, ensure_dll, bind_api
from storage import Storage

lib = ensure_dll()
bind_api(lib)
host = Host(lib, Storage(Path("simulator/data/nvram.bin")))

host.memory_write(16, b"\x01\x02\x03")
host.supply_off()
host.supply_on()
assert host.memory_read(16, 3) == b"\x01\x02\x03"
```

底层 `Storage.read / write / erase` 可用于测试和宿主实现；其本身不判断供电。正常设备访问使用 `Host.memory_*`。

## 与 APL 的边界

**simulator 只提供记忆存储方法，不自动保存或恢复任何业务字段。** 当前 APL ops 尚无存储接口，本次未修改 APL 的接口与保存策略。后续 APL 定义存储回调后，由宿主将回调接到 `Host.memory_*`，同时转换异常为约定错误码。

APL 决定字段、地址、记录版本、校验、写入时机及恢复行为。不能把含有指针的 APL 对象内存直接作为持久化格式。

## 文件与故障语义

每次内容变化的写入以临时文件、flush/fsync、原子替换提交；失败时保留上一份内存和文件内容。同样的数据不重复写入。`Storage.writes` 是当前存储实例内容变化的提交次数，不跨进程保存。

大小不符的已有文件会报错，原文件保留，不自动覆盖。此设备是可覆盖写入的字节存储模型，不模拟 Flash 擦写寿命、页时序或写入途中掉电的部分损坏。当前供电与写入同步执行，掉电只保留已完成的写入。

同一文件目前按单个仿真器进程使用，不支持多进程并发写入。
