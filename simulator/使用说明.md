# 使用说明

产品配置、编译预览与 SDK 导出见[产品配置与 SDK 导出](产品配置与SDK导出.md)。

## 构建和运行

当前验证环境：Windows、Qt 6.12.0 MinGW 64 位、MinGW 13.1、CMake 和 Ninja。CMake 要求 Qt 至少 6.5。

在工程根目录执行；安装位置不同时调整路径：

```powershell
$env:PATH = "C:\Qt\6.12.0\mingw_64\bin;C:\Qt\Tools\mingw1310_64\bin;C:\Qt\Tools\Ninja;C:\Qt\Tools\CMake_64\bin;" + $env:PATH
cmake -S simulator/workbench -B simulator/workbench/build -G Ninja -DCMAKE_PREFIX_PATH=C:/Qt/6.12.0/mingw_64 -DCMAKE_C_COMPILER=C:/Qt/Tools/mingw1310_64/bin/gcc.exe -DCMAKE_CXX_COMPILER=C:/Qt/Tools/mingw1310_64/bin/g++.exe
cmake --build simulator/workbench/build
simulator\workbench\build\apl_workbench.exe
```

程序保留内置 APL 作为初始预览，并自动绑定本地源码目录。保存 APL 实现后自动单独构建、重载 APL，不需要重建 simulator；左侧可选择源码目录，Ctrl+B 手动重载。详见[APL 开发与热重载](APL开发与热重载.md)。两份面板作为 Qt 资源内嵌，运行不需要 Python。

## 操作

- 左侧导航切换概览、产品配置、实时仿真、SDK 交付，快捷键 Ctrl+1～4。界面约定见[界面与交互设计](界面与交互设计.md)。
- 产品配置直接在页面内编辑。保存草稿不会影响运行实例；点击右上角“应用并预览”后才将草稿构建并上电。源码文件保存则自动重建最近一次请求应用的配置。
- 实时仿真顶部切换圆形面板 / 按键台，切换不会初始化 APL。
- 鼠标按住六键按钮，或用 Tab 选键后按空格 / Enter。松开是短按，保持 3 秒是长按。
- 右侧环境输入可用滑块或精确数值框调整；实际负载输出保持可见，诊断信息在“运行诊断”页签。
- 仿真顶部提供供电与暂停 / 继续。更多菜单提供重新上电、单步 10 ms、滤芯查询；菜单栏也保留这些入口。
- 面板 Power 键是正常开关机；加湿机型关机先风干。风干中短按 Power 重新开机，长按 3 秒立即结束风干进入待机。供电开关模拟外部上电 / 掉电，两者独立。
- 面板下方根据当前状态提示操作：风干倒计时、电源恢复操作、童锁解锁、暂停与熄屏唤醒。右侧“运行诊断”显示待机 / 正常运行 / 关机风干 / 产测，以及净化、加湿开关的当前值；实际输出仍以固定负载显示为准。


显示和按键业务由 APL 联动接口控制：

| 场景 | 三位数码管 |
|---|---|
| 上电 | 888，全灯自检 2 秒，随后待机熄屏 |
| 正常运行 | 净化显示 PM2.5，加湿显示湿度；一体机每 20 秒轮换 |
| 定时设置 | 显示小时数，H 闪烁；3 秒无操作后确认并恢复正常显示，Timer 键灯表示定时有效 |
| 恒湿设置 | 显示目标湿度或 OF，闪烁；3 秒无操作后确认 |
| 滤芯查询 | 仿真菜单选择“查询滤芯寿命”，显示剩余寿命 3 秒 |
| 产测 / 恢复出厂完成 | 分别显示 888 / CL |

一体机 Humidity 短按开关加湿，长按 3 秒进入恒湿设置，随后短按循环目标值。Timer 长按切换童锁，Speed 长按切换极速，Purify 长按配网，Light 长按切换睡眠。Light 短按关闭状态显示后，首次触摸只唤醒 3 秒，期间再次操作才执行按键功能。键灯独立于状态显示，图标和水位灯颜色由 APL 输出。


传感器输入范围：水位 0–4 段、PM2.5 0–1000、湿度 0–100%、温度 -20–60°C。这些是仿真输入范围。运行时净化启用会每秒读取空气质量传感器，加湿启用会读取湿度；温度目前没有业务使用。

## 负载、事件和调试信息

固定显示风机、加湿器、UV 和负离子实际收到的输出。未收到命令显示“未驱动”，断电显示停止。APL 用户档位与实际输出分开：风机和加湿器分别从 set_fan、set_pump 回调更新；风机按实际输出档位显示，不假设对应的 rpm。

仿真卡片底部的“事件记录”默认收起，展开后可筛选、跟随滚动并保存文本。按发生顺序保留最近 500 条事件：先记录六键短按 / 长按，再记录实际逻辑结果和显示变化。同值输入与输出不重复刷日志。

六个调试槽位默认空，由宿主按需调用 displaySet / displayClear 填入 APL 信息，不预绑定字段。方法见设计说明。

## 供电和存储

掉电停止 tick，清除运行内存与负载输出，不触发正常关机回调；再次上电重新初始化 APL。定时和童锁清除，传感器环境值、日志、调试槽位与存储保留。

宿主提供 4096 字节存储，初始全为 0xFF，文件位于 Qt AppLocalDataLocation 下的 nvram.bin，跨程序重启保留。无供电时拒绝存储访问。保存字段和恢复策略留给 APL，本仿真台不自动保存档位等业务状态。

## 验证

```powershell
ctest --test-dir simulator/workbench/build --output-on-failure
simulator\workbench\build\apl_workbench.exe --self-test
```

测试包括真实 APL 的核心行为、灯光键裁剪、文件存储，以及净化单开、加湿单开和两项同时开启配置下的命令 / 快照业务。工作台自检覆盖面板加载、按键、全灯、PM2.5 / 湿度轮换、定时延迟确认、恒湿设置、滤芯查询、熄屏唤醒、童锁、手势与结果事件、传感器采样、供电、固定负载与调试槽位。工作台自检截图输出到系统临时目录的 apl-workbench.png 与 apl-workbench-all-lamps.png；新工作区截图见[界面与交互设计](界面与交互设计.md)。
