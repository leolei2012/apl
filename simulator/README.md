# APL Studio

用于配置、仿真验证和导出本工程的 APL C 源码 SDK。Qt Widgets 提供四页工作区（概览、产品配置、实时仿真、SDK 交付），两份内置 QML 分别显示圆形面板和按键台。

使用流程：新建产品 → 配置功能 / 参数 / 按键 → 编译并预览 → 保存产品配置 → 导出 ZIP SDK。

保留：六键鼠标 / 键盘操作、传感器输入、固定负载状态、事件日志、上电 / 掉电、暂停 / 单步、4 KB 文件存储，以及六个按需填写的调试槽位。

从工程根目录运行：

```powershell
simulator\workbench\build\apl_workbench.exe
```

启动后自动绑定本地 APL 源码工程；修改并保存 C 实现后，只重建并重载 APL 模块，界面继续运行。可在左侧更换源码目录，Ctrl+B 手动重新加载。没有源码目录时仍可使用内置预览。预览需要本机 GCC / Clang；默认使用构建仿真台时的编译器，也可在产品菜单指定。公共接口或界面修改仍需重新构建 simulator。
