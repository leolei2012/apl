# APL 仿真台

只用于测试工程内的真实 APL C 库。Qt Widgets 提供调试窗口，两份内置 QML 分别显示圆形面板和按键台。

保留：六键鼠标 / 键盘操作、传感器输入、固定负载状态、事件日志、上电 / 掉电、暂停 / 单步、4 KB 文件存储，以及六个按需填写的调试槽位。

文档：

- [使用说明](使用说明.md)：构建、运行、操作与验证。
- [设计说明](设计说明.md)：APL 接线、存储、负载和显示方法。

从工程根目录运行：

```powershell
simulator\workbench\build\apl_workbench.exe
```

修改 APL 后用 CMake 重新构建仿真台。面板已内嵌，不需要另外配置 QML 目录、外设项目或控制程序。
