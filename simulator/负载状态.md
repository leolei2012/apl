# 固定负载状态

右侧依次显示传感器输入、固定负载、自定义信息和事件记录。最小窗口仍为 126 列 × 40 行。固定负载不占用六个通用槽位，也不会因清空槽位而消失。

## 状态来源

| 固定项 | 显示来源 |
|---|---|
| 供电 | 宿主外部供电状态 |
| 风机 | `Host.fan_set(rpm)` 实际接收到的转速命令 |
| 加湿器 | `Host.humidifier_set(state)` 实际接收到的开关命令 |
| UV | 已注入 APL 的 `uv_set` 回调，转交 `Host.uv_set(state)` |
| 负离子 | 已注入 APL 的 `anion_set` 回调，转交 `Host.anion_set(state)` |

风机与加湿器目前尚无 APL 输出回调，由后续宿主接线调用上述方法。改变 APL 档位或启用标志不会自行驱动负载。当前 APL 未主动调用 UV、负离子输出，因此初始显示“未驱动”。

## 方法与模型

```python
host.fan_set(1200)       # 模拟风机收到 1200 rpm 命令
host.fan_set(0)          # 停止
host.humidifier_set(1)   # 开启
host.humidifier_set(0)   # 关闭
host.uv_set(1)
host.anion_set(0)
```

风机输入为非负整数 rpm；开关输入为 0/1 或布尔值。非法值抛出 `ValueError`，不改变原状态。此处是理想负载：立即应用收到的命令，没有惯性、测速反馈、功耗或故障模型；显示的 rpm 不是传感器实测值。

尚未收到命令显示“未驱动”；收到关闭命令后显示“关闭”或“停止 / 0 rpm”。突然断电显示“停止（无供电）”，清除原输出；无供电时忽略有效控制命令。再次上电等待新的输出，不恢复断电前状态。

软件重置与外部供电不同：不单独改变负载记录，APL 初始化若发出输出，则由新输出更新记录。普通 Power 关机同样不会由仿真器擅自覆盖输出。

`Host.load_rows()` 返回固定负载的名称和值，供 TUI 与旧版面板共用。原调用计数仍保留在宿主中，不再用次数代替开关状态。

TUI 同时显示六个自定义槽位及最近三条事件，事件缓存保留最近 500 条，按 E 展开查看。

## 验证

