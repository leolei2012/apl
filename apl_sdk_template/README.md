# 产品源码模板

独立于 Studio 的版本化源码目录，历史名称不限制品类。

- air-care/0.1.0：从当前 APL 源码和原移植示例固定的 C11 快照，运行时不读取根目录源码，不依赖 Qt 界面。AP 专用生成器消费 adapter.json。
- lighting/1.0.0：独立灯控示例，不依赖 APL 库；提供自己的目录、getter / setter、输出回调和消费程序，使用 native-c-v1。

发布版本应保持冻结，业务与配置更新新建版本目录。作者提供源码、能力和参数描述、移植入口、文档和验证程序；平台负责配置、校验、构建和交付。生成 SDK 不依赖 Node.js。

详见 [模板接入约定](../apl_studio/docs/源码模板接入约定.md) 和 [产品标准化方向](../apl_studio/docs/产品标准化方向.md)。
